# StudyMate Demo Kit

Use this folder for the final local demonstration.

- `studymate-demo-unit-testing.docx`: upload this document to demonstrate extraction, grounded chat and Quiz source selection.
- `MANUAL_QUIZ_FALLBACK.md`: copy this Quiz into the manual creator if an external AI provider is unavailable.
- `DEMO_SCRIPT.md`: a concise 3 to 5 minute presentation route.

The DOCX is committed and ready to upload. To regenerate it after changing its source script, install `python-docx` and run:

```powershell
python .\scripts\create_demo_document.py
```
