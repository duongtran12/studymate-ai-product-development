# Optional AI provider setup

StudyMate always retrieves relevant excerpts from the course documents first. Without an AI provider, it returns those excerpts directly with their citations.

To let an OpenAI-compatible provider rewrite that evidence into a natural Vietnamese answer, set these local environment variables. Never commit the key.

```dotenv
STUDYMATE_AI_ENABLED=true
STUDYMATE_AI_BASE_URL=https://api.openai.com/v1
STUDYMATE_AI_MODEL=your-model-name
STUDYMATE_AI_API_KEY=your-secret-key
```

If the provider is unavailable, returns an invalid response, or has no configured key/model, StudyMate automatically uses the local evidence-based fallback. Citations remain generated by StudyMate, not by the provider.
