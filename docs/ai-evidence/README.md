# AI Evidence Log

Create one Markdown record for each material AI-assisted activity. Do not copy API keys, passwords, tokens, or private personal data into an evidence record.

## Record template

```md
# Evidence title

- Date:
- Owner:
- Related requirement or issue:
- Tool or model:
- Prompt version:

## Prompt

Write the prompt or a safe redacted summary.

## Output summary

Describe the useful result without pasting unnecessary private content.

## Human review

- What was verified:
- What was changed or rejected:
- Verification method: test, document comparison, or manual scenario.
- Reviewer:
```

## Naming

Use `YYYY-MM-DD-short-topic.md`, for example `2026-09-10-rag-answer-policy.md`.
